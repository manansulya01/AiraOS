# AiraOS

AiraOS is an experimental x86_64 operating system.

## Vision

A modern operating system built from the ground up with a clean kernel
architecture, security, networking, userland, graphical interface,
and eventually native AI capabilities.

## Planned Components

- x86_64 boot process
- Custom kernel
- Memory management
- Interrupt handling
- Hardware drivers
- Filesystem
- Process management
- Userland
- Shell
- Networking
- Security subsystem
- Graphical interface
- Native applications
- AI subsystem

## Development

AiraOS is developed and tested primarily with QEMU.

## Status

Early development.
